Technology Stack

Frontend

  • Vue 3 — Composition API throughout
  • Vite 8 — dev server & bundler
  • vue-router — client-side routing
  • axios — HTTP client to the API
  • Custom SVG charts, CSS Grid layouts

Backend

  • FastAPI — REST API framework
  • Pydantic — data validation & models
  • uvicorn — ASGI server
  • Managed with uv (Python package manager)
  • pytest + httpx — test suite

Data

  • Static JSON files in server/data/
  • Loaded fully into memory at startup
  • No database — changes do not persist
  • Restarting the server reloads from disk

Request / Data Flow

1
User interacts with a filter or page
The FilterBar component (Time Period, Warehouse, Category, Order Status) updates shared reactive state via the useFilters composable.
2
View requests data
A view (e.g. Dashboard.vue, Inventory.vue) calls a method on client/src/api.js, passing the current filter values.
3
API client builds the HTTP request
api.js serializes active filters into query-string parameters and issues a GET via axios to http://localhost:8001/api/....
4
FastAPI filters in-memory data
The endpoint applies apply_filters() / filter_by_month() over the in-memory lists loaded from JSON, then validates the response shape against a Pydantic model.
5
Response returns as JSON
FastAPI serializes the validated model(s) back to the client as JSON.
6
Vue stores & derives state
Raw results are stored in refs (e.g. allOrders, inventoryItems); templates render derived values through computed() properties, which re-run automatically when filters change.
